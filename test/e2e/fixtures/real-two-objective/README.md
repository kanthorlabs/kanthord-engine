# real-two-objective

The authored plan input of the P1-E5 onboarding journey, against the real repository of
`.env.e2e`.

One initiative, two objectives and four tasks, with no identity and every `depends_on` as a
relative path. It mirrors `../two-objective/` and differs in one field: each objective names
`repo: real`, the name the journey registers the real repository under.

The `plan/` prefix excludes this file from the import.
