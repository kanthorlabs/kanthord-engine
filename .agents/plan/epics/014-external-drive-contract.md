# EPIC 014 — External-drive contract and vocabulary

Status: **draft**.

## Goal

`docs/proposal/` states the external driver, and `src/domain/` holds each part of it as data. The five contract statements of `013-external-drive-overview.md:49-55` are amended in place, plus the `ready → pending` matrix cell. The run row and the attempt row carry a driver, the lease row carries an owner kind, the plan revision row carries an origin, completeness validity becomes one function enforced at the claim only, an objective's drive mode is pinned at its first claim, and the two concurrency classes exist as a closed discriminator. Every node state write names its trigger, and the trigger is one member of one closed union that covers the external drive and the internal drive together. **This epic is the block's one contract-ratification milestone, and it is the single named exception to the route-close rule of `013-external-drive-overview.md:100`.** It writes no route and it closes no vertical capability. It closes on `npm run verify` and on the domain suite. Every phase-1 route, token and test of EPICs 001 to 012 stays green.
